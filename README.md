# HillSec Enterprise Identity & Access Management Lab

## Project Overview

The **HillSec Enterprise Identity & Access Management (IAM) Lab** is a hands-on portfolio project that demonstrates the design, implementation, automation, and validation of a modern hybrid identity environment.

The project simulates enterprise Identity and Access Management operations by integrating **Okta Workforce Identity Cloud** and **Microsoft Entra ID** while implementing Role-Based Access Control (RBAC), identity lifecycle management, Microsoft Graph PowerShell automation, enterprise application integration, and hybrid identity concepts.

Rather than completing isolated product tutorials, this project follows a structured implementation approach similar to enterprise IAM deployments—from planning and design through validation and documentation.

This project was designed to:

- Configure authentication and authorization
- Integrate enterprise applications
- Demonstrate hybrid identity concepts

- Produce professional implementation documentation suitable for portfolio presentation

## About This Project

This project was developed as part of my professional Identity & Access Management learning journey to gain practical experience with enterprise identity technologies while building a portfolio that demonstrates planning, implementation, automation, validation, and technical documentation.

The environment is intended to model enterprise IAM concepts using production-inspired design principles while acknowledging the constraints of a lab environment.
