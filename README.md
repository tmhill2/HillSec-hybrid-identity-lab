

# HillSec Hybrid Identity Implementation

## Project Overview

The HillSec Hybrid Identity Implementation is a simulated enterprise Identity and Access Management (IAM) project designed to demonstrate the planning, implementation, and management of a modern hybrid identity environment.

The project integrates Okta Workforce Identity Cloud, Microsoft Entra ID, Active Directory, and Splunk to simulate enterprise identity operations while following IAM best practices. The implementation is being documented from initial planning through final deployment to showcase both technical and documentation skills.

---

## Project Objectives

- Design a realistic enterprise identity environment
- Implement Role-Based Access Control (RBAC)
- Configure Multi-Factor Authentication (MFA)
- Configure Single Sign-On (SSO)
- Integrate Microsoft Entra ID
- Integrate Active Directory
- Configure authentication policies
- Monitor authentication events using Splunk
- Document the complete implementation from planning through deployment
